Why this page is public. Every component in this library is held to one written standard, and this page shows where each one stands against it, gaps included. Nothing here is hand-written: a script rebuilds it from the repository whenever a component changes.

The scored checks are structural. They prove each component has tests, a story, styling docs, a usage guide and an editor snippet, and that it follows the shared code rules. They can't prove the logic is sound, so each component also gets an independent whole-component review, recorded in the Reviewed column.

That second step earns its place. The first review was of a navigation header that already passed every structural check. It found a prop whose value was silently ignored, menus that stayed open after navigating, state shared between two instances on one page, and layout with no fallback for older Safari.
