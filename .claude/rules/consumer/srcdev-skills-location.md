# Where srcdev-nuxt-components skills live

A skill named as "skill `x.md` (srcdev-nuxt-components)" is at
`.claude/skills/srcdev-nuxt-components/x.md`. Per-component usage docs are in its `components/`
subfolder (`.claude/skills/srcdev-nuxt-components/components/<component-name>.md`). Inside the
srcdev-nuxt-components repo itself, the same files are directly under `.claude/skills/`.

Why: the layer's rules name skills rather than linking a path, so they read the same in the
library repo and in consuming apps.
